Overview

A six-channel simultaneous temperature control system for industrial laboratory flasks, using SSR-based burst-fire actuation and NTC temperature sensing. Local UI with 7-segment display and rotary encoder. Designed for continuous industrial operation.

Problem

Laboratory processes require precise, stable temperature control across multiple flasks simultaneously. Phase-angle control of SSR heaters injects electrical noise that can affect sensitive measurement instruments. A cleaner actuation strategy was needed.

Solution

An SSR burst-fire control strategy with a 500 ms window: instead of chopping the AC waveform, the controller switches the SSR on and off over complete mains cycles, delivering the required average power while generating no phase-angle switching noise. Six independent channels run simultaneously on a single STM32.

Architecture

  • Controller: STM32 Black Pill (ARM Cortex-M)
  • Channels: 6 independent temperature loops
  • Actuation: SSR burst-fire, 500 ms window
  • Sensing: NTC thermistors
  • UI: 7-segment display + rotary encoder
  • Target: continuous industrial operation

My role

Firmware design and implementation on STM32, burst-fire control algorithm, NTC linearization, multi-channel scheduling, UI integration (7-segment + encoder), and full system validation.

Results

  • 6 channels controlled simultaneously on a single MCU
  • Low-noise SSR burst-fire actuation
  • Continuous industrial operation
  • Local UI with encoder-based parameter setting
