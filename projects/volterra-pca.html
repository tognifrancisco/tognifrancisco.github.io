Overview

A method for identifying and synthesizing amplitude-dependent nonlinear systems, using exponential swept-sine excitation at multiple amplitudes, Volterra kernel extraction, and a continuous amplitude model built from PCA with explicit shape-scale separation. Preliminary experimental validation on a symmetric nonlinear system shows leave-one-out prediction error below 1% on all kernel orders.

Problem

Many real systems — audio transducers, amplifiers, power devices — behave differently at different excitation amplitudes. Classical linear identification captures one operating point only. Full Volterra models are general but suffer from the curse of dimensionality: the number of coefficients grows exponentially with nonlinear order and memory length. What's needed is a compact, continuous model in amplitude that can predict the system response for any input within the calibrated range.

Solution

The method has three stages. Identification: exponential swept-sine (ESS) excitation at exponentially distributed amplitudes, with coherent averaging (M = 8) to improve SNR. After deconvolution with an inverse filter that includes amplitude correction, the k-th order Volterra kernel appears at a known delay Δt_k = T·ln(k)/ln(f₂/f₁). Each kernel is isolated with an adaptive Tukey window (α = 0.1) based on a 3σ noise threshold.

Continuous model: a kernel evolution matrix is built for each order — one row per amplitude. Each kernel is normalized by its peak before PCA, so the principal components capture only shape variation. The scale (peak amplitude) is modeled independently with cubic splines in log-log space. This separation reduces the number of components needed and improves extrapolation at the extremes of the amplitude range.

Synthesis: the PCA subspace is factorized — for each order, the output is generated by a bank of fixed FIR filters (the mean shape plus the PCA modes), combined linearly with the interpolated scores and multiplied by the predicted gain. When the target amplitude changes, only the scores and gain are reevaluated — the FIR filters stay fixed. Odd-order kernels are symmetric and even-order kernels antisymmetric, which halves the number of multiplications per filter.

Method details

  • Excitation: exponential swept-sine (ESS) from 20 Hz to 20 kHz over T = 4 s at f_s = 44.1 kHz
  • Amplitude range: exponentially distributed (equally spaced in log scale). A_max below clipping / THD threshold. A_min determined by SNR of the highest-order kernel (target SNR ≥ 25 dB)
  • Averaging: M = 8 coherent averages per amplitude (+9 dB SNR)
  • Inverse filter: time-reversed sweep with exponential amplitude correction to flatten the spectrum
  • Kernel delay: Δt_k = T·ln(k)/ln(f₂/f₁). For k = 2, 3, 4, 5: 0.40 s, 0.64 s, 0.80 s, 0.93 s
  • Kernel isolation: adaptive Tukey window (α = 0.1), flat region ~90% of length, with 3σ noise threshold
  • Continuous model: PCA with shape-scale separation. Kernel normalized by peak before decomposition; scale modeled with cubic splines in log-log space
  • Synthesis: fixed FIR filter bank (mean shape + PCA modes), weighted by interpolated scores and predicted gain. Symmetry exploited (odd symmetric, even antisymmetric) to halve multiplications
  • Orders extracted: up to 5 Volterra kernels per measurement

Why shape-scale separation?

A direct PCA on the kernel matrix mixes two effects: the shape of the kernel changes with amplitude, and its overall scale changes too. The scale dominates, so the PCA spends components capturing it, leaving fewer for the shape. Normalizing by peak first confines the scale trend to a univariate gain model — robust and smooth — while the PCA operates on shape variables with approximately constant mean. This reduces the number of components needed and substantially improves extrapolation at the boundaries of the amplitude range.

My role

Full R&D of the method: mathematical derivation of the noise model, ENOB gain, coherent averaging, inverse filter construction, adaptive windowing, PCA shape-scale separation, spline interpolation, and the synthesis architecture with symmetry exploitation. MATLAB simulation and preliminary experimental validation on a symmetric nonlinear system.

Results

  • Method fully derived mathematically: ESS amplitude distribution, minimum amplitude based on kernel SNR, optimum number of coherent averages, kernel delay formulas, shape-scale PCA
  • Leave-one-out cross-validation: prediction error below 1% on all kernel orders (up to k = 5) on a symmetric nonlinear system
  • Synthesis from predicted kernels reproduces the measured output, including at amplitudes not included in training
  • Synthesis architecture designed for fixed FIR filters with scalar updates — suited to real-time implementation
  • Preprint available

Status

Preprint. The method is fully described and validated experimentally on a representative symmetric nonlinear system. Real-time implementation on DSP/FPGA is planned as future work — the architecture is designed for it (O(L) per sample, fixed filters, scalar updates), but has not been implemented in hardware yet.
